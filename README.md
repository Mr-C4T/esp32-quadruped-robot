# 🕷️ ESP32 Quadruped Robot

A small quadruped robot powered by **8 HobbyKing servo motors and 2 ESP32 microcontrollers**.

The robot is built using 11 laser-cut 3 mm MDF pieces and 8 custom 3D-printed PLA knee joints.

## 🛠️ Hardware

### Mechanical Parts
- 11 laser-cut 3 mm MDF pieces (`.svg`)
- 8 3D-printed PLA knee joints (`knee.stl`)
- 8 HobbyKing servo motors
- 8 aluminum servo horns
- 20 M3 × 25 mm spacers
- ~100 M3 × 8 mm screws

### Electronics
- 2 ESP32 microcontrollers (robot and remote)
- Adafruit 16-Channel PWM/Servo Driver
- DC voltage regulator
- 12V LiPo battery
- Power switch
